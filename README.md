# E-Commerce App

A modern E-Commerce App built using **Jetpack Compose**, **Firebase**, **Room Database**, and **Hilt Dependency Injection** following **MVVM Architecture**.

---

## Features
- User Authentication with Firebase Auth
- Product Listing Screen
- Product Details Screen
- Add to Cart Functionality
- Local Cart Management using Room DB
- Firestore Database Integration
- Modern UI with Jetpack Compose
- Bottom Navigation
- Search Products

---

## Architecture
UI (Compose) → ViewModel → Repository → Firebase / Room DB

---

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM
- Hilt DI
- Firebase Authentication
- Firebase Firestore
- Room Database
- Coroutines & Flow

---

## Main Components
- Authentication Module
- Product Listing
- Product Details
- Cart Management
- Firestore Database
- Room Cart Database
- Hilt Modules

---

## Firebase Usage
- Firebase Auth → User Login & Signup
- Firestore DB → Store Product Data
- Room DB → Manage Cart Offline
